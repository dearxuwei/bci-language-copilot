# Roadmap

## Month 1: Public Prototype

- Build a mock BCI probability stream.
- Implement phrase-bank language completion.
- Add P300/SSVEP decoder interfaces.
- Create CLI demo and a lightweight UI placeholder.
- Report keystroke savings, top-k candidate match, and completion latency.
- Publish README, architecture diagram, and demo video.

## Month 2: Offline EEG Validation

- Integrate one public P300 or SSVEP dataset.
- Implement xDAWN + LDA for P300 or FBCCA for SSVEP.
- Compare baseline spelling with language-assisted prediction.
- Add reproducible experiment configs.

## Month 3: Live-Ready Interaction

- Add BrainFlow / LSL input adapter.
- Build Streamlit or web dashboard.
- Add session replay and phrase personalization.
- Prepare a workshop/demo paper draft.

## Long-Term

- Personalized phrase banks.
- Multilingual assistive communication.
- Patient-centered phrase set design.
- Clinical collaborator evaluation.
- Privacy-preserving local language prediction.
