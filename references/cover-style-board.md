# Cover Style Board: BCI-Language Copilot

This style board summarizes cover-art patterns observed from Nature-family and IEEE biomedical/neuroengineering promotional visuals. Do not copy protected cover art into the repository; use these as design principles.

## Reference Sources

- Nature / Scientific Reports article pages and promotional images for BCI and neuroscience papers.
- Nature Biomedical Engineering / Nature Machine Intelligence cover-style conventions: dark cinematic space, single conceptual object, volumetric glow, restrained typography.
- IEEE TBME / EMBC graphical-abstract conventions: engineered pipeline, signal traces, grids, electrode layouts, transparent overlays.

## Style Principles

- Use one dominant scientific metaphor, not a collage.
- Strong depth: foreground brain/head, midground signal pathway, background abstract computation field.
- Palette: deep navy/black base, cyan neural signal, violet AI layer, amber assistive output accent.
- Use thin luminous strokes, semi-transparent glass panels, and sparse annotation.
- Make it look like a cover teaser, not a dashboard.
- Keep text minimal and integrated into the composition.

## Composition Target

`human neural signal -> BCI selector -> AI language manifold -> completed expression`

The final asset should work at:

- GitHub README hero size
- conference slide title page
- social media preview crop
- poster top band
